2. What does a multi-site F&B operation need the system to support?

How I would execute this

I would provide the agents with the instructions and documents together, but make one point particularly clear: they should work in parallel, not sequentially.

The coordinating agent should receive all outputs and reconcile them before producing Documents 09–15.

That is the foundation for deciding what to build first — and for demonstrating that the technology is grounded in actual hospitality operations rather than being a collection of disconnected interfaces.
